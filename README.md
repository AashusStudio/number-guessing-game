# Number Guessing Game 🎯

This is a simple number guessing game I made using Python.
It also has a basic login/signup system and stores user data in a JSON file.

---

## What it does

* Lets users create an account and log in
* Generates a random number between 1–100
* Gives 7 attempts to guess it
* Tells you if the number is higher or lower
* Rewards points based on how fast you guess
* Saves your balance so it stays even after closing

---

## How to run

1. Clone the repo
2. Run the file:

```
python main.py
```

That’s it.

---

## Files

* `main.py` → game logic
* `data.json` → stores user info (password, balance)
